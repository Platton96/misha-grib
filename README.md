# Миша Гриб

Браузерная игра для Миши: бросай грибы в лукошко, соединяй одинаковые и вырасти Царь-гриб.

**Играть:** https://codewordparty.com/misha-grib/

## Управление

- Телефон: веди пальцем по полю и отпусти, чтобы бросить гриб.
- Компьютер: веди мышью и кликай, или жми ← → (A, D) и пробел. Пауза на Esc или P.

## Как устроено

Статический сайт без сборки: HTML, CSS, JavaScript и физический движок [Matter.js](https://brm.io/matter-js/) (MIT) в папке `vendor`. Все грибы и звуки создаются кодом.

Запуск локально:

```bash
python3 -m http.server 8080
```
